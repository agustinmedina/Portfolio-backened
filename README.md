# Portfolio Backend API

Backend project developed as part of my backend portfolio to demonstrate REST API development, authentication, database integration, and backend best practices.

## Overview

This project provides a backend service with structured endpoints, database connectivity, and API architecture intended to showcase backend development skills.

Main goals of the project:

- Build scalable backend architecture
- Implement REST API principles
- Practice database integration
- Apply clean project organization
- Improve backend portfolio quality

Installation

Clone repository:

git clone https://github.com/agustinmedina/Portfolio-backened.git

Move to project folder:

cd Portfolio-backened

Install dependencies:

npm install

Create environment file:

PORT=3000
DATABASE_URL=your_database_url

Run development server:

npm run dev

Run production:

npm start
API Example

Example endpoint:

GET /api/example
